# Scientific data verification notes

Before academic submission, add a source/reference and measurement conditions for each material. Critical temperatures and critical fields depend on composition, pressure, sample quality, temperature and field orientation. Do not compare Hc, Hc1 and Hc2 as the same quantity. Specify doping/composition for cuprates and iron-based materials. H3S requires extreme pressure (about 150 GPa). Where no single universal field value is appropriate, describe the value as anisotropic or condition-dependent rather than inventing a number.
